===============================================================================
  ANTRIAN - MINI PC SETUP GUIDE (Windows 11 + nginx + PHP + MySQL)
===============================================================================

WHAT YOU END UP WITH
--------------------
  Mini PC (Windows 11)
    - runs the app: nginx -> php-cgi (x4) -> MySQL
    - Screen 1 (TV)    : /display  - calls numbers, plays the voice
    - Screen 2 (Kiosk) : /kiosk    - visitors take a ticket, ticket prints
  Operator PC (same network)
    - opens http://antrian/operator in a browser and calls numbers

  After setup, the daily routine is: turn everything on. That's it.

FIXED FOLDERS (the scripts assume these - keep them exactly like this)
  C:\antrian   the app (this git repository)
  C:\php       PHP
  C:\nginx     nginx

FILES IN THIS FOLDER (C:\antrian\deploy\windows)
  nginx.conf          nginx configuration (used in place, no copying)
  start-server.bat    starts php-cgi + nginx at boot and restarts them if they die
  stop-server.bat     stops the server (for maintenance)
  start-screens.bat   opens the TV and kiosk windows full-screen at logon
  install.ps1         one-time: creates the startup tasks, firewall rule, power settings
  update.bat          pulls new code and rebuilds; use it for every update
  SETUP-GUIDE.txt     this file

Allow about 1.5 - 2 hours for the first setup. Follow the steps in order.


===============================================================================
 STEP 1 - PREPARE WINDOWS
===============================================================================

 1.1  Use a LOCAL Windows account for the Mini PC (not a Microsoft account),
      e.g. "antrian". This is the account that shows the TV and kiosk.

 1.2  Rename the PC to "antrian"
        Settings > System > About > Rename this PC  ->  antrian  -> Restart
      Other PCs can then use http://antrian/ instead of an IP address.

 1.3  Network
        - Connect the Mini PC with a network CABLE (not Wi-Fi).
        - In your router, add a DHCP reservation so the Mini PC always gets
          the same IP (e.g. 192.168.1.50). Write it down: ____________
        - Settings > Network & internet > Ethernet > Network profile type:
          Private

 1.4  Screens
        Settings > System > Display
        - Click "Identify" to see which number is the TV and which is the kiosk.
        - Choose "Extend these displays".
        - Pick which one is the main display ("Make this my main display").
        - Note each screen's resolution and position. You need them in STEP 8.
        - Easiest: keep Scale at 100% on both screens.

 1.5  Sound comes out of the TV
        Settings > System > Sound > Output  ->  choose the TV (HDMI)

 1.6  Indonesian voice for the announcements
        Settings > Time & language > Speech > Manage voices > Add voices
        -> Indonesian (Indonesia)

 1.7  Kiosk touchscreen (only if the kiosk screen is a touchscreen)
        Control Panel > Tablet PC Settings > Setup... > Touch input
        Tap the KIOSK screen when it asks. On the TV, press Enter to skip.
        Without this, touches on the kiosk may land on the TV.

 1.8  Ticket printer
        - Install the thermal printer's Windows driver.
        - Settings > Bluetooth & devices > Printers & scanners:
          turn OFF "Let Windows manage my default printer",
          then open the thermal printer and click "Set as default".
        - In Printing preferences, set the paper size (58mm or 80mm).
        - Print a Windows test page to check it works.

 1.9  Windows Update must not restart the PC during office hours
        Settings > Windows Update > Advanced options > Active hours
        -> Manually, e.g. 06:00 - 18:00

 1.10 BIOS (press Del/F2 at power-on; the name differs per brand)
        - "Restore on AC Power Loss" / "After Power Failure" = Power On
          (after a power cut, the Mini PC turns itself back on)
        - Optional: "Wake on RTC" / "Auto Power On" at e.g. 06:30 on weekdays


===============================================================================
 STEP 2 - INSTALL SOFTWARE
===============================================================================

 2.1  Visual C++ Redistributable (PHP needs it)
        https://aka.ms/vs/17/release/vc_redist.x64.exe  -> install

 2.2  PHP 8.4 (or 8.3), "VS17 x64 Non Thread Safe" ZIP
        https://windows.php.net/download/
        - Extract so that C:\php\php.exe and C:\php\php-cgi.exe exist.
        - Copy C:\php\php.ini-production to C:\php\php.ini
        - Open C:\php\php.ini in Notepad and make these changes
          (remove the ";" at the start of the line where it exists):

            extension_dir = "C:\php\ext"        <- must be the FULL path

            extension=curl
            extension=fileinfo
            extension=mbstring
            extension=openssl
            extension=pdo_mysql
            extension=zip

            zend_extension=opcache
            opcache.enable=1
            opcache.enable_cli=0
            opcache.memory_consumption=128

            upload_max_filesize = 8M
            post_max_size = 10M
            date.timezone = Asia/Jakarta

        - Add C:\php to PATH:
            Start > "Edit the system environment variables" >
            Environment Variables > System variables > Path > Edit > New
            -> C:\php   -> OK on every window
        - Open a NEW Command Prompt and check:   php -v
          and:                                   php -m
          The list from "php -m" must include: curl, fileinfo, mbstring,
          openssl, pdo_mysql, zip, Zend OPcache.

 2.3  nginx for Windows (stable version ZIP)
        https://nginx.org/en/download.html
        Extract so that C:\nginx\nginx.exe exists.
        (Do NOT edit C:\nginx\conf\nginx.conf - our config lives in the repo.)

 2.4  MySQL Community Server 8.4 LTS
        https://dev.mysql.com/downloads/installer/
        - Choose "Server only".
        - Leave "Configure MySQL Server as a Windows Service" and
          "Start the MySQL Server at System Startup" ticked.
        - Set a root password and write it down somewhere safe.

 2.5  Git          https://git-scm.com/download/win        (defaults are fine)
 2.6  Composer     https://getcomposer.org/Composer-Setup.exe
                   (it should find C:\php\php.exe by itself)
 2.7  Node.js LTS  https://nodejs.org/   (only used to build the frontend)
 2.8  Google Chrome  https://www.google.com/chrome/

      Open a NEW Command Prompt and check that each of these prints a version:
        git --version
        composer --version
        node --version
        npm --version


===============================================================================
 STEP 3 - GET THE APP
===============================================================================

 Open Command Prompt:

   git clone https://github.com/jooemrp/antri.git C:\antrian
   cd /d C:\antrian
   git checkout chore/minipc-deploy

 (Once that branch is merged, use "git checkout main" instead. update.bat
  always pulls whichever branch is checked out.)


===============================================================================
 STEP 4 - CREATE THE DATABASE
===============================================================================

 Start > "MySQL 8.4 Command Line Client" > enter the root password, then:

   CREATE DATABASE antrian CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER 'antrian'@'localhost' IDENTIFIED BY 'PUT-A-STRONG-PASSWORD-HERE';
   GRANT ALL PRIVILEGES ON antrian.* TO 'antrian'@'localhost';
   FLUSH PRIVILEGES;
   EXIT;


===============================================================================
 STEP 5 - CONFIGURE THE APP (.env)
===============================================================================

   cd /d C:\antrian
   copy .env.example .env
   notepad .env

 Change these lines (add any that are missing):

   APP_NAME="Antrian Disdukcapil"
   APP_ENV=production
   APP_DEBUG=false
   APP_URL=http://antrian
   APP_TIMEZONE=Asia/Jakarta        (WITA: Asia/Makassar, WIT: Asia/Jayapura)

   LOG_STACK=daily
   LOG_LEVEL=warning

   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=antrian
   DB_USERNAME=antrian
   DB_PASSWORD=PUT-A-STRONG-PASSWORD-HERE      (the one from STEP 4)

   SESSION_LIFETIME=720             (operators stay logged in for 12 hours)

 Save and close. Never share or commit this file.

 IMPORTANT: whenever you change .env later, run this afterwards:
   php artisan optimize


===============================================================================
 STEP 6 - FIRST BUILD
===============================================================================

 Open Command Prompt AS ADMINISTRATOR
 (Start > type "cmd" > right-click > Run as administrator), then:

   cd /d C:\antrian
   composer install --no-dev --optimize-autoloader
   php artisan key:generate
   php artisan storage:link
   deploy\windows\update.bat
   php artisan db:seed --force

 update.bat takes a few minutes. It must end with "Update finished."
 db:seed creates the first admin account, the services (KTP, KK, Akta),
 example lokets and default branding.


===============================================================================
 STEP 7 - INSTALL THE STARTUP TASKS
===============================================================================

 Still logged in as the Mini PC account from 1.1, open PowerShell AS
 ADMINISTRATOR (Start > type "powershell" > right-click > Run as administrator):

   powershell -ExecutionPolicy Bypass -File C:\antrian\deploy\windows\install.ps1

 It should print four [ok] lines. If it prints a WARNING about the network
 being Public, run the command it shows (or redo step 1.3).

 Start the server now (without rebooting):

   schtasks /run /tn "Antrian Server"

 Wait ~10 seconds, then open Chrome on the Mini PC and go to http://localhost
 You should see the login page.


===============================================================================
 STEP 8 - PUT EACH WINDOW ON THE RIGHT SCREEN
===============================================================================

 start-screens.bat opens the TV window at (0,0) and the kiosk window at
 (1920,0). That is right if the TV is the main display, 1920 pixels wide,
 and the kiosk sits to its RIGHT in Settings > System > Display.

 If your layout is different, create this file (it is not tracked by git):
   C:\antrian\deploy\windows\screens.local.bat

 and set a point that lies on each screen. Examples:

   Kiosk is main (1920 wide), TV to its right:
       set "TV_X=1920"
       set "KIOSK_X=0"

   TV is main and 2560 wide (or 4K at 150% scale), kiosk to its right:
       set "KIOSK_X=2560"

   Kiosk is to the LEFT of the main display:
       set "KIOSK_X=-1000"

 Test it:  double-click C:\antrian\deploy\windows\start-screens.bat
 To close the full-screen windows: click the window, then press Alt+F4.
 Close both before you test again.


===============================================================================
 STEP 9 - AUTO-LOGIN AND REBOOT TEST
===============================================================================

 9.1  Turn on automatic login for the Mini PC account:
        - Settings > Accounts > Sign-in options: turn OFF
          "For improved security, only allow Windows Hello sign-in..."
        - Press Win+R, type  netplwiz  and press Enter.
        - Untick "Users must enter a user name and password to use this
          computer", click OK, then enter the account's password twice.

 9.2  Restart the Mini PC and do NOT touch anything. Within ~1 minute:
        [ ] Windows logs in by itself
        [ ] the TV shows the display page, full screen
        [ ] the kiosk shows the ticket page, full screen
        [ ] the TV does NOT show an "Aktifkan Suara" box
        [ ] touching a service on the kiosk prints a ticket, with no print dialog
        [ ] after STEP 10/11: calling that ticket from the operator PC plays
            the chime and the voice on the TV, without anyone clicking
        [ ] on another PC, http://antrian/ opens the login page
            (if not, try http://<the IP from 1.3>/)


===============================================================================
 STEP 10 - SECURE AND CONFIGURE THE APP
===============================================================================

 On any PC, open http://antrian/login and sign in with the seeded admin:
     email:    admin@disdukcapil.test
     password: password

 Straight away:
   [ ] Settings > Profile: change the email to a real one
   [ ] Settings > Security: change the password
   [ ] Sidebar > Layanan: check the services
   [ ] Sidebar > Loket: rename the example lokets and officers, delete extras
   [ ] Sidebar > Tampilan: name, logo, colours, running text

 Create one account per operator. Note: the /register page is still open to
 anyone on the network; only share the address with staff.


===============================================================================
 STEP 11 - OPERATOR PC
===============================================================================

 1. Install Google Chrome.
 2. Right-click the desktop > New > Shortcut, and paste as the location:
      "C:\Program Files\Google\Chrome\Application\chrome.exe" --app=http://antrian/operator
    Name it "Antrian Operator".
 3. Open it and log in with "Ingat saya" (Remember me) ticked.
    The operator stays logged in from then on.
 4. Use a network cable if possible.

 If http://antrian/ doesn't open on this PC, use the Mini PC's IP instead,
 e.g. --app=http://192.168.1.50/operator


===============================================================================
 DAILY ROUTINE
===============================================================================

 Morning:  turn on the TV, the Mini PC and the operator PC.
           Operator double-clicks "Antrian Operator".
           Ticket numbers restart from 001 every day automatically.

 The TV turns its sound on by itself. If it ever shows an "Aktifkan Suara"
 box, click it once (or see TROUBLESHOOTING > No voice).

 Evening:  press the Mini PC's power button once (Windows shuts down
           properly) and turn off the TV.


===============================================================================
 UPDATING TO A NEW VERSION
===============================================================================

 1. Command Prompt AS ADMINISTRATOR:
      C:\antrian\deploy\windows\update.bat
 2. Wait for "Update finished."
 3. Restart the Mini PC. The TV and kiosk keep showing the old version
    until their windows are reopened, and a restart does that for you.
 4. On the operator PC, press F5 once.

 If it says "Update FAILED", the old version keeps running. Read the error
 above that line.

 If you changed nginx.conf and nginx won't start, check C:\nginx\logs\error.log


===============================================================================
 TROUBLESHOOTING
===============================================================================

 Where to look:
   C:\antrian\storage\logs\server-watchdog.log   restarts of php-cgi / nginx
   C:\antrian\storage\logs\laravel-*.log         app errors
   C:\nginx\logs\error.log                       nginx errors

 Stop / start the server by hand (as administrator):
   C:\antrian\deploy\windows\stop-server.bat
   schtasks /run /tn "Antrian Server"

 "502 Bad Gateway"
   php-cgi isn't running. Check server-watchdog.log. Usually php.ini is
   wrong: run  php -m  and compare with step 2.2.

 "500 Server Error"
   Look in laravel-*.log. Often the database password in .env is wrong.
   After fixing .env, run:  php artisan optimize

 Nothing on http://localhost at all
   Something else may be using port 80. Check with:
     netstat -ano | findstr :80
   The last number is the process ID; look it up in Task Manager > Details.
   (Turn off IIS / "World Wide Web Publishing Service" if it is enabled.)

 Works on the Mini PC but not from the operator PC
   - The network profile must be Private (step 1.3).
   - Try the IP instead of http://antrian/.
   - Run install.ps1 again (it recreates the firewall rule).

 Windows are on the wrong screens
   Adjust screens.local.bat (step 8). Close both windows (Alt+F4) and
   double-click start-screens.bat again.

 Print dialog appears / nothing prints
   Close ALL Chrome windows on the Mini PC and run start-screens.bat again
   (the silent printing flag only applies to a freshly started Chrome).
   Check that the thermal printer is the Windows default printer.

 No voice, only the chime (or nothing)
   - If the TV shows an "Aktifkan Suara" box, Chrome was started without
     the sound flag. Close ALL Chrome windows on the Mini PC and run
     start-screens.bat again (or just click the box for today).
   - Check the Windows sound output is the TV (step 1.5).
   - Check the Indonesian voice is installed (step 1.6), then restart.

 git says "detected dubious ownership"
   git config --global --add safe.directory C:/antrian

 Note: start-server.bat watches processes by name (php-cgi.exe, nginx.exe).
 Don't run other nginx or PHP servers (XAMPP, Laragon, Herd) on the Mini PC.
